# SOLAS

SOLAS (meaning 'Light' in Irish) is a development of the SEDONA Monte Carlo
radiative transfer code.

This repository is under development. The active source code lives on
the `development` branch.

## Origin

SOLAS is developed from SEDONA, originally written by Daniel Kasen.

- SEDONA repository: https://github.com/dnkasen/pubsed

## References

If you use this code, please cite the SEDONA method papers:

- Kasen, D., Thomas, R. C., & Nugent, P. 2006, "Time-dependent Monte
  Carlo radiative transfer calculations for three-dimensional supernova
  spectra, light curves, and polarization", ApJ, 651, 366
  (https://ui.adsabs.harvard.edu/abs/2006ApJ...651..366K)
- Roth, N., & Kasen, D. 2015, "Monte Carlo radiation-hydrodynamics with
  implicit methods", ApJS, 217, 9
  (https://ui.adsabs.harvard.edu/abs/2015ApJS..217....9R)
